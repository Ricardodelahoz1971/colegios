**Al final del script, antes de renderizar el layout final HTML, añadir la lógica de división:**

```php
// Verificar si hay saltos de página en el contenido
if (strpos($html_contenido, 'ares-salto-pagina-render') !== false) {
    // Dividir el contenido por los saltos de página
    $partes = explode('<div class="ares-salto-pagina-render"></div>', $html_contenido);
    
    // Identificar bloques de cabecera para duplicar
    $bloques_cabecera = [];
    preg_match_all('/<div[^>]*data-tipo="(logo|titulo_colegio|lema_colegio|metadatos)"[^>]*>.*?<\/div>/s', $partes[0], $matches);
    if (!empty($matches[0])) {
        $bloques_cabecera = $matches[0];
    }
    
    // Construir múltiples contenedores
    $html_final = '';
    foreach ($partes as $indice => $parte) {
        if (trim($parte) === '') continue;
        
        $html_final .= '<div class="print-container">';
        
        // Duplicar cabecera en cada página (excepto la primera si ya la tiene)
        if ($indice > 0 && !empty($bloques_cabecera)) {
            foreach ($bloques_cabecera as $bloque_cabecera) {
                $html_final .= $bloque_cabecera;
            }
        }
        
        $html_final .= $parte;
        $html_final .= '</div>';
    }
    
    $html_contenido = $html_final;
}
```

**Nota:** Asegúrate de que la variable `$html_contenido` contenga el HTML renderizado de todos los bloques antes de aplicar esta lógica de división.
